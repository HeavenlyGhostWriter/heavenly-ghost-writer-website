# Heavenly Ghost Writer
This website is purely based on HTML and CSS, without being dependent on JavaScript, and other JavaScript Libraries, designed to be timeless and efficient 

This was made, with the help of **Artificial Intelligence **, specifically Gemini  

## The System In Action
This Website Do Not Github Pages to display the website but a shared hosting, but it utilizes GitHub Features such tracking changes, which is great,  I used Termux in my phone And Acode Editor .

**Acode Editor** is a versatile code IDE in android so far in my knowing, I used it to create this website, the free version have ads, but the app work, hope, I will not have problem using it in the future 

**Termux** a powerful app so far in my disposal to help me in this website development, its really versatile, it handles other programming languages, especially Python3 and this also handle *Git*, I use for main two purpose, Website deployment and Git integration

## Deployment System
In the past, I used Github Actions to automatically deploy my site changes and make it online accessible, I update changes in my Local, push changes to Github and Github Publish changes to my website, it works great but I changed my approach ,  I manually published changes to my Site, I made changes locally and push it, and Github serve as my website code repository and great UI for GIT 

**deploy.py** is my tool for online publication of my local website to online, it utilizes *FTP* and other built in Python3 tools, it was made by Gemini, it serve as replacement of GitHub Actions, it works well in Termux,  *deploy_tracker.json* its a part of 'deploy.py', it tracks what what uploaded
